# 晨昏之下（Godot 4.x）

类《暗黑地牢》手机游戏：经营 + 回合制战斗。Godot 4.x，GDScript，Android 横屏。

## 当前进度（V0.1-3 / WS-5）

已实现**废墟遗迹地图 + 探索循环**（GDD v1.0 第四章）：

- 程序化网格地图生成（4×4~6×5），节点类型：战斗房/宝箱房/事件房/安全房/起始房/关底房，按任务长度（短/中/长）配比。
- 房间探索动作：侦查（受火把档位影响成功率）→ 探索（触发战斗/宝箱/事件/安全）→ 检查（发现陷阱线索）。
- 陷阱（铲子/徒手解除）与门锁（钥匙/铲子/盗贼撬锁）。
- 火把：团队共享 0~100，战斗外每房间 −5，三档效果曲线（明亮/昏暗/黑暗）。
- 遇敌切换战斗场景（当前为占位，WS-4 落地后替换）；探索/撤退后返回城镇闭环。

## 目录

- `scenes/` — Main 状态机（城镇↔地城↔战斗↔结算）与各场景
- `scripts/` — 场景脚本；`autoload/` 为数据加载器与全局状态
- `data/dungeons.json` — 地图/火把/陷阱/门锁/掉落/遇敌数值配置（改数值不改代码）
- `tests/` — 无头自检脚本（生成器 150 次校验 + 全流程冒烟 + 场景流转）

## 运行

```bash
godot --path .            # 启动（进入城镇，选择长度后出发）
# 无头自检
godot --headless --path . res://tests/test_main.tscn
godot --headless --path . res://tests/test_scene_flow.tscn
```
